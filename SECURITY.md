# Security policy

tslow's watcher runs elevated, so security reports are welcome and taken seriously.

Please report vulnerabilities privately through GitHub's
["Report a vulnerability"](https://github.com/glingus/tslow/security/advisories/new) form, not as a
public issue. Include what you did, what you expected and what happened.

The security model (protection levels, the database as untrusted input, the update trust model) is
described in `docs_obsidian/Architecture.md`.
